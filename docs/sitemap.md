# Proposed site structure and navigation

## Pages

```
/                         Home
/about                    About Exron: background, management experience, mission, values, group affiliation
/capabilities             Procurement categories, sourcing services, logistics coordination, operational support
/industries               Government, military installation support, defense contractors, construction, infrastructure, industrial, commercial
/government-contracting   For contracting officers: verified registrations, procurement process, capability statement, procurement contact
/contact                  Contact details, general inquiry form, secure-transmission note
/submit-rfq               RFQ submission
  /submit-rfq/received    Confirmation with reference number (noindex)
/privacy  /terms          Legal
/brand                    Visual identity (noindex, review only)
/admin                    Content manager (noindex, invite only)
```

## Status

| Page | Status | In search engines |
| --- | --- | --- |
| `/` | Complete (approved homepage design) | Yes |
| `/about`, `/capabilities`, `/industries`, `/government-contracting`, `/contact` | Complete, in the homepage design, awaiting client review | Yes |
| `/submit-rfq` | Complete and working | Yes |
| `/privacy`, `/terms` | Drafts awaiting legal review | No, until approved |
| `/options/` | Alternative homepage designs, review only | Never |
| `/brand` | Review only | Never |

## Main navigation (all devices)

Home · About Exron · Capabilities · Industries We Serve · Government Contracting · Contact

- The red **Submit an RFQ** button is separate from the menu and always visible in the header.
- On phones and tablets the menu opens full screen, with the RFQ button pinned at the bottom.
